# Changelog

## 2.1.0
- Added a uGUI glass shader with backdrop sampling, tint, frost, rim lighting, screen-space refraction and rounded corners.
- Added separable Gaussian blur shaders for Built-in RP and URP.
- Added Built-in RP camera capture and blur component.
- Added optional URP Renderer Feature assembly: compatibility pass for URP 14 and native RenderGraph path for URP 17+ (Unity 6), with XR-aware Blitter shader path.
- Added reusable ScriptableObject glass presets assignable in the GlassGraphic Inspector.
- Added World Space Canvas (XR) creation menu.
- Added pointer hover/press intensity feedback.
- Expanded Hierarchy menu with legacy uGUI Button, Text, Input Field and Dropdown factories.
- Corrected TMP slider handle and dropdown item layout.

## 2.0.0
- Added Hierarchy / GameObject menu for Liquid Glass UI.
- Added native uGUI and TextMeshPro control factories.
- Added Glass Canvas, Panel, Image, Raw Image, Button, TMP Text, TMP Input Field, TMP Dropdown, Toggle, Slider, Scroll View and Scrollbar.
- Added MIT license and UPM package metadata.
